Almacenamiento de imágenes (Cloudinary)

Firebase guardará los datos y usuarios. Cloudinary alojará logotipos y fotografías. Los videos se mostrarán desde YouTube. No introduzcas API Secret ni contraseña aquí.

Cloud name y preset ya están precargados. Cada imagen tiene un límite individual de 10 MB; el peso total de una galería puede ser mayor. Las imágenes que superen 9,5 MB se optimizan automáticamente a WebP antes de subirlas. Los videos se enlazan desde YouTube y no consumen almacenamiento de Cloudinary. Pulsa Guardar para registrar la configuración en Firestore.
